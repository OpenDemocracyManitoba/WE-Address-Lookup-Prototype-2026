# Use curated Contest identities and Contest-scoped Candidate Records

Issue #2 reset the earlier Person and Candidacy identity model because it exposed unsupported identity work to the Operator. Winnipeg Election now curates identities only for the 2026 Contests and their Electoral Areas; each Candidate Record belongs directly to one Contest and retains its source identifier and source-published name as provenance. Source labels map explicitly to canonical Contests, but the project does not create separate Person IDs, Candidacy IDs, or hand-authored canonical name parts unless later evidence establishes that need.
