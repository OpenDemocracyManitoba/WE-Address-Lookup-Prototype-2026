# Confirm normalized data without a publication state machine

Authoritative source data can contain test records, destructive mutations, unknown labels, and incomplete coverage, so a later import will preserve its Source Snapshot, validate normalization, summarize changes, and ask the Operator to confirm replacing normalized election data. A failed required source, unresolved Contest assignment, conflicting duplicate, or declined confirmation leaves the prior data unchanged. Issue #2 supersedes the earlier multi-stage publication design: there is no separate approval command or publication state machine, and the displayed Election Phase is a simple explicit configuration choice.
