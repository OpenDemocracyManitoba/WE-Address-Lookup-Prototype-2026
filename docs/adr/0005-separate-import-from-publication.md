# Confirm normalized data without a publication state machine

Authoritative source data can contain test records, destructive mutations, unknown labels, and incomplete coverage, so each import preserves its Source Snapshot, validates normalization, summarizes changes, and asks the Operator to confirm replacing normalized election data. A failed required source, unresolved Contest assignment, conflicting duplicate, or declined confirmation leaves the prior data unchanged. Issue #2 superseded the earlier multi-stage publication design: there is no separate approval command or publication state machine. The displayed Election Phase is an explicit configuration choice. Registration includes only active Registered records; Nomination includes only active Nominated records. Winnipeg Election will launch after the nomination period with this setting changed to Nomination.
