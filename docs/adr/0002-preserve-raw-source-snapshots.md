# Preserve raw source snapshots

Authoritative election sources can mutate or remove records without retaining dependable candidate-level history, while Winnipeg Election must retain evidence of former and withdrawn Candidate Records and explain imported changes. Every successful import therefore preserves an immutable, time-stamped Source Snapshot before normalization. The current normalized data may replace or omit former records; no normalized or public Candidate history is required because the Source Snapshots provide the required historical evidence. This adds modest storage and ingestion complexity but prevents source history from being irretrievably lost.
